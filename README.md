# cazis-cards

Публичные картинки бота [@CazisBot](https://t.me/CazisBot): приветствие, приглашение друга, дуэль.

Telegram скачивает картинки по ссылке со своих серверов, а до наших серверов в России он не достаёт — поэтому картинки лежат здесь.

Адрес файла: `https://raw.githubusercontent.com/ITadde/cazis-cards/main/bot/<файл>.jpg`

Поменял картинку — меняй и версию в настройке бота `BOT_CARDS_VERSION`, иначе Telegram покажет старую из своего кеша.
